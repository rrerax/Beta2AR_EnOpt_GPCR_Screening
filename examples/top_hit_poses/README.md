# Top-Hit Pose Examples

This directory contains representative docking pose files and Vina logs for top-ranked β2-AR candidates. The files are provided for visual inspection in molecular viewers such as PyMOL, ChimeraX, or Discovery Studio Visualizer.

The complete score table is available at `results/tables/docking_scores.csv`. This directory keeps a compact subset of poses rather than the full raw docking workspace.
